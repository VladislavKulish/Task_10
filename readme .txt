Ключевые моменты
Фикстуры в conftest.py — единый источник данных для всех тестов, без дублирования.
Параметризация — все повторяющиеся сценарии перебираются через @pytest.mark.parametrize, включая индексы фикстур-списков.
process_data покрыта полными операциями, операциями без суммы, без даты, с некорректным operationAmount (строка вместо dict), с currency без dict, только с from, пустым словарём и не-dict входом.
Порог 80% enforced через --cov-fail-under=80 — сборка упадёт, если покрытие опустится

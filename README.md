# README: Утилиты для маскировки платёжных данных и преобразования дат

## О проекте

Проект предоставляет набор функций для безопасной обработки чувствительных данных:

- **Маскировка номеров карт и счетов** без использования регулярных выражений (`re`).
- **Преобразование формата даты** из ISO (`YYYY-MM-DDTHH:MM:SS.ffffff`) в `ДД.ММ.ГГГГ`.
- **Единый интерфейс** для выбора операции и валидации входных данных.

Подходит для предобработки данных перед отображением в UI, логированием, экспортом и т.п.

---

## Требования

- Python 3.8+
- Внешние зависимости не требуются
